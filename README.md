# ML LAB 7-To implement the Naive Bayes Classification algorithm using suitable dataset.

## Theory
Naive Bayes is a supervised machine learning algorithm based on Bayes' Theorem. It predicts the class of a data sample by calculating the probability of each class.

In this experiment, **Gaussian Naive Bayes** is used to classify raisins into two classes: **Kecimen** and **Besni**, based on numerical features such as area, perimeter, axis lengths, eccentricity, and extent.

The dataset is divided into training and testing sets. The model is trained using the training data, and its performance is evaluated using accuracy, precision, recall, F1-score, and a confusion matrix.

Gaussian Naive Bayes assumes that numerical features follow a Gaussian (normal) distribution within each class.

## Objective
To implement the Naive Bayes Classification algorithm using the Raisin Dataset and evaluate its performance.

## Result
The Gaussian Naive Bayes model is trained to classify raisins into Kecimen and Besni classes and evaluated using standard classification metrics.
